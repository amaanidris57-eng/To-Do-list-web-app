To-Do List Web App

Description

A simple To-Do List application built using HTML, CSS, and Vanilla JavaScript to manage daily tasks.

Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Instant updates without page reload

Technologies Used

- HTML
- CSS
- JavaScript
- VS Code
- Live Server

How to Run

1. Open the project in VS Code.
2. Install the Live Server extension.
3. Right-click "index.html".
4. Select Open with Live Server.

Objective

To create a simple, interactive task management application using front-end technologies.
